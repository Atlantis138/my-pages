新中式

自述

Neo-Chinese Aesthetics二〇一〇年代至今

新中式不是哪个流派的正式名称。它是近十几年中文设计界的一个通称，指用现代的网格、字体和克制的配色，去表达传统的审美：宋瓷的素净，文人画的留白，古籍的版式，一方朱红的印。

它在网页上其实只有三件事：大片的空白，一处朱红，几条细线。这一页也只用了这三样。

节气

壹

计白当黑

原理

清代书法家邓石如说，字画「疏处可以走马，密处不使透风，常计白以当黑」。意思是：空白不是画剩下的地方，它和墨一样要经营。新中式放到网页上，第一条规矩就是这个。

留白不是算出来的比例，而是删出来的：每往右一档，就拿掉几样东西，再把剩下的收拢到一边。

  1. 留白要有形状

    把内容收拢到一角或一侧，让空白连成一整块。四处均匀地空着，只会显得稀松；一边密、一边空，才有「疏密」。

  2. 只点一处朱红

    整屏最多一个高饱和的颜色，面积很小，通常是一方印。它负责把视线带到最要紧的地方，所以不能到处都是。

  3. 用线，不用框

    分隔靠一条一像素的细线，或者干脆靠距离。不用阴影，不用色块卡片，圆角不超过两三个像素。

贰

五个来处

来历

「新中式」这个词最早多用在家具和室内设计上，后来才扩展到平面和网页。它没有创始人，也没有宣言，取材却相当固定，大致是下面五处。每一处都给了网页一样具体的东西。

  • 宋瓷

    汝窑的天青、定窑的白、龙泉的青，都是一色到底的单色釉，不靠纹饰取胜。

    给网页：配色。一两种低饱和的颜色，大面积平涂，不做渐变。

  • 文人画

    南宋的马远、夏圭喜欢只画一角或半边，人称「马一角，夏半边」，其余全是空的。

    给网页：构图。内容偏在一侧，不对称，空白占大半。

  • 古籍

    雕版印刷留下了一整套版式：版框、界行、天头地脚，以及从刻本里演变出来的宋体字。

    给网页：网格与字体。细线分栏、竖排标题、宋体正文。

  • 篆刻

    一幅字画上，印章是唯一的红色。字凸起的叫朱文，字凹下的叫白文；盖在哪里也有讲究。

    给网页：强调色。一小块朱红，用在标记、状态和落款上。

  • 园林

    明代计成在《园冶》里讲「巧于因借，精在体宜」。月洞门和漏窗把远处的景框进来，叫作框景。

    给网页：图片的外形与节奏。用圆形、扇形裁切图片；长页面一屏一景。

它是怎样流行起来的

  1. 一九八〇年代起

    靳埭强等香港设计师把水墨、笔触和文房器物放进现代海报，证明传统元素可以和现代版式共处。

  2. 二〇〇六

    贝聿铭设计的苏州博物馆新馆开馆：白墙、灰色的石材线条，以墙为纸的片石假山。「新中式」在建筑上有了一个公认的样本。

  3. 二〇〇八

    北京奥运会的视觉系统用了祥云纹和印章式的会徽，并把中国红、琉璃黄、青花蓝、玉脂白等整理成一套有名字的色彩系统。

  4. 二〇一三起

    故宫陆续推出《胤禛美人图》《韩熙载夜宴图》《每日故宫》等应用，传统题材第一次有了成规模的、做工讲究的数字界面。

  5. 二〇一八

    李宁在纽约时装周的发布引出「国潮」一词，茶饮、美妆、文创品牌纷纷跟进，新中式成了消费品的主流视觉之一。

  6. 二〇二二

    北京冬奥会开幕式用二十四节气倒计时；同年春晚的舞蹈《只此青绿》让青绿山水的配色家喻户晓。

流行得快也带来了套路化：祥云、仙鹤、烫金、做旧的宣纸纹理被到处套用。怎样避免，见「宜忌」一节。

方向

竖排从右往左读。它很有味道，但网页的滚动方向是上下的，长文竖排会变成横向滚动，谁都不习惯。所以竖排只用在标题、题签、落款这类一两行的短句上，正文仍然横排。竖排里的阿拉伯数字和西文默认是躺倒的：两三位的数字用「纵中横」并成一格，更长的改写成汉字。

色：一纸、一墨、一朱、一间色

纸色和墨色占去九成以上，朱砂只是一个点。第四种颜色叫间色，用来给标题和图形一点温度；本页的间色随节气所在的季节变：春用竹青，夏用石青，秋用赭石，冬用黛蓝。色名取传统颜料和织物的叫法，色值是本页自定的，传统色并没有统一的标准色值。点色块可以复制。

组件与响应式

做成组件时，新中式几乎是在做减法：去掉底色、阴影和圆角，剩下字、线和距离。这样的界面很安静，但也容易让人看不出哪里能点。所以可以交互的东西必须有一个明确的记号：一条底线，一块墨色，或者一点朱红。下面的组件都可以操作。

了解冲泡方法

取舍

新中式的门槛看着低：一张宣纸底、一个毛笔字、一方印，似乎就成了。也正因为这样，它最容易做俗。下面仿照老黄历的写法，列出宜和忌。

宜

  • 茶、香、器物、服饰等生活方式品牌
  • 博物馆、文旅、非遗、古籍数字化
  • 节气、传统节日的专题页
  • 内容不多、希望人慢下来看的页面

忌

  • 信息密集的后台与工具：留白和竖排都会拖慢操作
  • 需要强烈促销感的页面：它天生安静，喊不出声
  • 面向不读中文的用户：竖排、印章和书法都会变成纯装饰

写成代码

实现

新中式用到的 CSS 并不多，难处在中文排印的细节：竖排、标点、字体的体积。下面是本页用到的几段关键写法。

容易踩的坑

  • 竖排容器没有高度。竖排时文字先向下排，排满容器的高度才换到左边一列。不给高度，所有字会排成一长条。
  • 竖排溢出的方向是横的。内容超出时出现的是横向滚动条，而且从右向左。这是长文不要竖排的根本原因。
  • 中文字体很大。一款中文字体动辄几兆。用 Google Fonts 时它会按 unicode-range 切片、按需下载；自己托管就要做子集化，只留用到的字。
  • 书法字体会缺字。缺的字回退到宋体，夹在毛笔字中间非常显眼。标题文案定稿前先在字体里验证一遍。
  • 朱红在深色底上会刺眼。夜间模式不能直接沿用同一个红。本页在深色下把文字用的朱色调亮、降了一点饱和，印章的底色则保持不变。
  • 滤镜不要动。feTurbulence 的计算量不小。远山是静态的一次性渲染；给它加上持续的动画，手机会明显发热。
  • 灰不要用透明度叠出来。用半透明的黑做淡墨，叠在不同底色上深浅会变，对比度没法保证。直接给一个实色。
  • 别用繁体来「显得古」。简体环境里夹用繁体或异体字，读屏软件和搜索都会受影响，读者也未必认得。气质靠版式，不靠字形。
