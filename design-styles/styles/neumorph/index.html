新拟态

Soft UI — 从同一块材料里「挤」出来的界面

元素与背景是同一种颜色，没有边框，也几乎没有色块。只靠一道亮阴影和一道暗阴影，就让按钮像从软塑料表面凸起，或者被按进去。它在 2020 年前后风靡设计社区，又因为难以使用而迅速降温。

这一页就用新拟态写成。右边的旋钮控制着整页唯一的光源，拖动它，你会看到所有阴影一起转向。

01 · 原理

一亮一暗，两道阴影

新拟态的全部魔法只有一句 CSS：在元素背光的一侧投下暗影，在迎光的一侧投下亮影。两者都与背景同色系，于是元素看起来不是「放在」表面上，而是表面本身鼓了起来。

亮影：迎光一侧 暗影：背光一侧 元素与背景同色
  1. 同色元素的底色和它所在的表面完全一样，不靠颜色区分。
  2. 单一光源整页只有一个光源方向，所有元素的亮影和暗影都朝同一边。
  3. 亮暗对称亮影与暗影偏移量相同、方向相反，模糊半径通常是偏移量的两倍。
  4. 大圆角柔和的形状才像软材料，直角会让阴影显得生硬。
.raised {
  background: #E4E9F0;          /* 与父元素同色 */
  border-radius: 24px;
  box-shadow:  12px  12px 24px #B4BDCA,  /* 暗影 */
              -12px -12px 24px #FFFFFF;  /* 亮影 */
}

02 · 来历

拟物化的一次温柔回潮

名字由 new 与 skeuomorphism 拼成，意思是「新的拟物化」，也常被叫作 Soft UI。它出现在扁平化统治界面多年之后，像是设计师对立体质感的一次怀旧。点击时间轴上的节点查看每个阶段。

03 · 形态

四种基本形态

改变阴影的方向和背景渐变，同一块材料就能呈现四种不同的起伏。整套语言几乎都由这四种形态组合而成。

06 · 可用性

美，但不好用

新拟态降温的根本原因不是审美疲劳，而是可用性。一切都靠浅浅的阴影区分，对比度天生不足：哪个能点、哪个已经按下，常常要猜。

小测验：哪个开关是打开的？

三个按钮里只有一个处于按下（开启）状态。凭感觉点一下。

 

对比度体检

按当前配色实时计算。WCAG 2.1 要求界面组件的边界与相邻颜色至少 3 : 1，正文文字至少 4.5 : 1。

    把它改得能用

    1. 状态双重编码按下或开启时，除了凹陷，再加上强调色、图标或文字变化。
    2. 给可交互元素描边一道与文字同色、低不透明度的细边，就能把组件边界的对比度拉上来。
    3. 清晰的焦点环键盘用户看不出阴影的细微变化，焦点必须用明显的颜色标出。
    4. 正文不靠阴影文字一律用足够深的颜色，标题浮雕只作装饰。
    5. 尊重系统设置用户开启「增加对比度」时（prefers-contrast: more），自动切到增强样式。

    增强模式作用于整页：描边、强调色与焦点环。打开后再做一次上面的小测验。

    07 · 用法

    把它当作调味，而不是主菜

    整站使用新拟态，几乎注定会遇到对比度和层级的问题。更好的做法是在一个以其他风格为主的界面里，挑一两个控件用它来增加触感。

    适合

    • 单一功能的小工具：计算器、计时器、音乐播放器，控件少而大。
    • 智能家居与硬件面板：模仿实体按键，与产品工业设计呼应。
    • 局部点缀：一个开关、一个旋钮、一张会员卡片。
    • 视觉概念与作品集：展示质感与氛围，不承担复杂任务。

    慎用

    • 信息密集的后台与表单：几十个同色凸起块会让页面失去层级。
    • 需要强调行动的页面：主按钮和普通按钮长得几乎一样。
    • 彩色或图片背景：阴影依赖纯色底，背景一花就失效。
    • 纯白或纯黑背景：亮影或暗影没有余地，立体感消失。

    四个常见错误

    每组左边是错误示范，右边是改正后的样子。它们同样受页首旋钮控制，转动光源时差别会更明显。

    光源不统一

    右边那块的阴影方向反了，看上去像一个坑，又像光从两边同时照来。整页必须共享同一个光源方向，最好写成变量，而不是每个组件各写一套偏移。

    阴影用纯黑和纯白

    半透明黑做暗影、纯白做亮影，在浅灰蓝的底上会发灰发脏，换到深色模式更刺眼。阴影色应从底色推导：色相不变，只把明度调亮或调暗。

    偏移大、模糊小

    模糊半径比偏移量还小，阴影边缘就会变硬，元素像一张叠在上面的纸片，而不是从表面里鼓起来。模糊一般取偏移量的两倍左右。

    正文也做成浮雕

    浮雕字和背景同色，只能靠阴影辨认，读几行就累，对比度也远低于要求。浮雕只留给少数大标题，正文和数值一律用足够深的实色。

    08 · 实现

    写好它的几个要点

    用变量统一光源

    把阴影的偏移方向写成 CSS 变量，整页共用。本页的旋钮只改了两个变量：--sx 和 --sy。

    阴影色从底色推导

    亮影是底色提亮，暗影是底色压暗，而不是纯白和纯黑。换底色时阴影跟着变，才不会发脏。

    别直接给 box-shadow 做动画

    大模糊半径的阴影重绘很贵。可以把两种状态的阴影分别放在伪元素上，只切换透明度。

    深色版要重新调

    深色底上亮影要克制，暗影要更深；直接反转颜色会显得浑浊。点右上角的开关看看本页的深色版本。

    /* 光源方向：暗影偏移的单位向量 */
:root {
  --bg: #E4E9F0;
  --hi: #FFFFFF;  --lo: #B4BDCA;
  --sx: 0.71;   --sy: 0.71;
}
.nm-raised {
  --x: calc(var(--sx) * var(--d));
  --y: calc(var(--sy) * var(--d));
  background: var(--bg);
  box-shadow: var(--x) var(--y) calc(var(--d) * 2) var(--lo),
              calc(var(--x) * -1) calc(var(--y) * -1)
              calc(var(--d) * 2) var(--hi);
}
.nm-inset {
  box-shadow: inset var(--x) var(--y) var(--d) var(--lo),
              inset calc(var(--x) * -1) calc(var(--y) * -1)
              var(--d) var(--hi);
}
/* 用的时候只需给出「高度」 */
.button { --d: 8px; }

    本页的设计令牌

    颜色一栏按当前明暗模式实时计算对比度。亮影和暗影的对比度天生很低，所以它们只能做装饰，信息一律交给文字和强调色。

    令牌值用途对比度（对底色）

    本页的所有立体效果都由 CSS box-shadow 绘制，没有使用图片。
    页首右侧的复原按钮可以把光源、明暗和所有组件恢复到初始状态。
