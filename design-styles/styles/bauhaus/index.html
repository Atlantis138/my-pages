包豪斯

1919 年，建筑师格罗皮乌斯在魏玛创办了一所学校，想让艺术家、工匠和工业重新坐到一张桌子旁。它只存在了十四年，搬了两次家，最后在纳粹的压力下解散。它留下的形、色、字和构图方法，后来成了现代设计的基础语法。

这一页就用这套语法写成：只有圆、方、三角，红、黄、蓝，黑与白。

1

Grundlagen

把一切拆回基本元素

包豪斯的新生入学先上半年预备课程，要把学过的风格统统放下，从材料、形和色这些最基本的东西重新学起。它的视觉语言也是这样搭起来的：几种基本形、三种原色加黑白、一种不加装饰的字，再按功能把它们组织起来。

Form形

圆、方、三角。复杂的东西由它们组合出来：台灯是半球加圆柱，字母是圆加竖线。

Farbe色

红、黄、蓝加黑白，平涂，不用渐变和阴影。颜色是结构的一部分，用来区分和强调，不是填充。

Schrift字

无衬线、几何化，常常全部小写。粗黑线和色条也算排版元素，用来组织阅读顺序。

Komposition构图

不对称、对角线、大块留白。元素放在哪里，由它要传达什么决定，而不是由「好看」决定。

两句常被挂在包豪斯名下的话

「形式追随功能」

出自美国建筑师路易斯·沙利文 1896 年的文章《高层办公楼的艺术考量》，比包豪斯早了二十多年。包豪斯继承了这种想法，但这句话不是它说的。

「包豪斯风格」

格罗皮乌斯本人反对这个说法。他在 1935 年的《新建筑与包豪斯》里写道，如果真的出现一种「包豪斯风格」，那就意味着学校的失败——它要教的是方法，而不是一种样式。

3

Form und Farbe

黄三角、红方、蓝圆

康定斯基在包豪斯教形式与色彩课。他相信每种形和色都有自己的「张力」，性格相合的形和色放在一起会互相加强。页首问卷的标准答案就来自这套理论。

三角 × 黄

三个锐角向外刺，是最有方向、最活跃的形；黄色明亮刺眼，向外扩张。

方 × 红

水平与垂直互相抵消，方形稳定、沉重；红色饱满有力，稳稳停在原地。

圆 × 蓝

没有角，也没有方向，圆是内敛、完整的形；蓝色深远，向内退去。

问卷的真相

1923 年收回的答卷里，多数人给出了和康定斯基一样的答案。但研究者后来指出，答卷的大多是包豪斯师生，早就熟悉老师的理论；之后的心理学实验也没能复现这种一致。与其说它证明了一条规律，不如说它是一堂训练感受力的课。

同一种颜色，两种样子

约瑟夫·阿尔伯斯 1923 年起在包豪斯任教，后来在耶鲁写成《色彩的互动》（1963）。他最有名的练习，是让同一块颜色在不同的底色上看起来像两种颜色。所以包豪斯的配色从来不是孤立地挑颜色，而是安排颜色之间的关系。

右边两个小方块，哪个更深？想好了再把它们连起来。

网页上同一个灰色的次要文字，放在不同底色的卡片上，深浅看起来会不一样。挑颜色要在真实的背景上看，别只在白底上挑。

4

Schrift

全部小写，不加装饰

包豪斯把文字也当成构图材料：无衬线、几何化，可以很大，也可以旋转；粗线和色条负责安排阅读顺序。1925 年底起，学校的印刷品一律只用小写字母，信纸下方印着理由——

用圆和直线造字母

拜耳 1925 年设计的「通用字体」只有小写。既然一套字母就够了，那就让它尽可能简单：大多数字母由一个正圆和一两条直线组成。

下面的字按这个原则重画，只是示意，并不是拜耳的原字体。打开作图线看看它们是怎么搭起来的。

  • b、a、u、h 共用同一个圆
  • 竖线与圆相切，笔画处处等粗
  • x 高度正好等于圆的直径
  • s 由两个半径减半的圆接成

中文没有大小写

小写规则只适用于拉丁字母。包豪斯式的中文排版要靠别的手段：粗黑体、悬殊的字号、横排和竖排混用，以及把文字直接压在色块和粗线上——就像这一页的标题和页首那条红色竖带。

Komposition

不对称的平衡

古典版式沿中轴对称，稳但呆板。包豪斯把元素推离中心，再用大小、颜色和距离让画面重新平衡——像一杆秤：大的靠近支点，小的要放得更远。

示意：这里的「视觉重量」只按面积计算。实际上颜色越深、越饱和，看起来就越重。

网页上首屏常见的「一侧大标题、另一侧小图形」就是这杆秤：大的靠近版心，小的推向边缘。

对角线

倾斜的文字和色条让画面产生运动感，莫霍利-纳吉和拜耳都常用这一招。

网页上只用在首屏或分隔带，倾斜的文字别超过一行。

粗线划分

粗黑线把版面切成区域，也规定了视线的先后顺序。

网页上用 3–12px 的实线分隔区块，比卡片阴影更清楚。

出血

大图形冲出画面边缘，版面就显得比纸张更大。

网页上给容器加 overflow: clip，免得撑出横向滚动条。

留白

把内容挤到一角，剩下的大片空白反而成了画面的主角。

网页上首屏敢于留空，操作区域却要紧凑。

Plakat

做一张包豪斯海报

每按一次「重新构成」，程序就按下面四条规矩重摆一次，图形的颜色跟随你在页首的问卷答案。选「分享图」会得到 1200 × 630 的版式，下载 PNG 后可以直接用作网页的 og:image 分享卡片。

8

Anwendung

什么时候用，怎么不用错

包豪斯的语法强烈、好认，适合需要一眼被记住的场合。同样的大色块和几何字体，放到信息密集的地方就会变成噪音。

适合

  • 展览、文化与艺术机构海报式的首屏、活动页和导视。
  • 品牌活动与着陆页需要一眼被认出、被记住的场合。
  • 教育与入门内容基本形和原色天然好懂，适合讲解结构。
  • 设计系统的点缀层插图、图标、空状态和数据之外的装饰。

慎用

  • 后台、表格与表单大色块会和真正需要注意的数据抢注意力。
  • 长篇正文几何字体的正圆字怀适合标题；长文换成更易读的无衬线体。
  • 需要细腻情绪的品牌原色和粗线条太直接，难以表现柔和与高级感。
  • 全小写的界面文案小写会抹掉专有名词和句首的提示，按钮和说明保持正常大小写。

六个常见错误

加上渐变和投影

渐变和投影让图形变成「物体」，包豪斯的图形是平面上的色块。保持平涂，层次交给大小和位置。

三种颜色平均分

红黄蓝各占三分之一，画面就像一面旗帜，没有主次。让一种颜色占大面积，另外两种只做点缀。

一切居中对称

图形、标题、线条全部摆在中轴上，画面稳定却毫无张力。把主体推离中心，用留白去平衡它。

黄底上压白字

铬黄非常亮，白字在上面的对比度只有 1.8 : 1，远低于正文要求的 4.5 : 1。黄底上一律用黑字；红底和蓝底上才用白字。

装饰抢走了操作

表单旁边放一个大红圆，提交按钮却是细线框，用户的视线先落在装饰上。最强的颜色留给最重要的行动，装饰缩小、退到角落。

只靠颜色区分状态

订单旁边的圆点只有颜色不同，色觉障碍用户和黑白打印时都分不清哪个出了问题。换成圆、三角、方三种形状，再写明状态。

9

Technik

用 CSS 画包豪斯

基本形用几行 CSS 就能画出来，难的是几个不显眼的坑。下面这些都是做这一页时实际遇到的。

  1. 形与色分开写用 --ci、--sq、--tri 表示「圆的颜色」「方的颜色」「三角的颜色」。页首的问卷只改这三个变量，整页的图形就一起换色。
  2. clip-path 会裁掉焦点环三角形用 clip-path 画，但 outline 也会被一起裁掉。把 clip-path 放在内层元素上，焦点环画在外层按钮上——右上角的三角复原按钮就是这样做的。
  3. 叠印在深色背景上会失效mix-blend-mode: multiply 让颜色与底色相乘，深色底上一切都会变黑。本页切到深色模式时改回 normal。
  4. 用 CSS 变小写，别改源文本text-transform: lowercase 只改变显示。源文本里的专有名词和德语名词照常大写，读屏软件和搜索引擎拿到的是原文。
  5. 网格要不对称用 5fr 3fr 2fr 这样悬殊的比例代替平均分栏，并写成 minmax(0, 5fr)，长单词才不会撑破栏宽。
  6. 出血不要撑出滚动条冲出边缘的大图形放进 overflow: clip 的容器。它和 hidden 一样会裁切，但不会生成滚动容器，里面的 position: sticky 照常工作。
  7. 首屏大字随容器缩放标题用 clamp() 设上下限，或者在容器查询里用 cqi，让构图在任何宽度下保持同样的比例（见第 6 节的响应式示例）。
  8. 装饰对读屏软件隐藏纯装饰的圆、方、三角加 aria-hidden="true"；用图形做的按钮一定要有文字或 aria-label。
  9. 动效只动 transform几何形的旋转和位移交给 transform，不触发重排；在 prefers-reduced-motion: reduce 下关掉。

.square   { aspect-ratio: 1; background: var(--sq); }
.triangle { aspect-ratio: 1; }

  background: var(--tri);

}
