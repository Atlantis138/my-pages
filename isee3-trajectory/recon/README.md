# 轨道重建脚本

页面 `../index.html` 由 `isee3.src.html` 模板加上两份数据生成：

```
cd v2
python3 fit_all.py      # 约 1 分钟：对逐小时星历做稳健的局部定轨，输出 nodes.pkl
python3 build.py        # 约 1 分钟：拼接轨道、导出 ../track.json 和 ../model.json
cd ..
python3 build_page.py [artifact.html]   # 生成 ../index.html（含 GitHub Pages 需要的 HTML 外壳）；可选再输出一份不带外壳的 Artifact 版本
```

需要 `numpy`、`scipy`。JPL Horizons 的查询结果缓存在 `v2/cache/`（不入库，首次运行会自动下载）。

## 数据（`data/`）

- `isee3_dp_ephem.asc`：NSSDC 逐小时 GSE 星历，1978-08-13 至 1987-02-07，48,293 条，含机动标记（`aareadme_isee3_dp_ephem`）。
- `icetrja.asc`：NSSDC 日心坐标预报，1984—1997，每日一条（`icetrjdy_fmt.txt`）。只用来做交叉检验。

## 方法（`v2/`）

| 时段 | 来源 | 处理 |
|---|---|---|
| 1978-08 — 1987-02 | NSSDC 逐小时星历 | `fit_all.py`：每 6 小时（近地、近月时）或 12 小时取一个节点，用前后各半天的数据在日地月引力模型（`dyn2.py`，太阳、月球取 JPL DE 星历）中做稳健最小二乘定轨；节点之间把相邻两条弹道平滑混合。1984 年后每 2 天一个节点，窗口 ±2 天。 |
| 1987-02 — 2014-01 | JPL 2014 轨道解 | `helio2.py`：把 Horizons 的 ICE（-111）2014-01-01 状态在八大行星加月球的引力模型中向前反推。到 1987-02 与 NSSDC 星历相差约 0.0006 AU，接缝处用 40 天平滑过渡。 |
| 2014 | JPL Horizons | 直接取 -111 的逐小时地心矢量。 |
| 彗星 | JPL Horizons | 21P、1P 在相遇时刻的密切根数（`model.json`）。 |

原始星历有四处系统误差，前三处在 `base.py`、`fit_all.py` 中改正，第四处在 `build.py` 中处理：

1. **每年 1 月初的坐标系错转。** 每年 1 月 1 日起 7—12 天内，GSE 坐标绕黄极整体转了 −0.246°（1981、1985 年为 +0.77°），相当于太阳 1/4 天或 3/4 天的运动量，像是原始处理时的日期错误。转角和区间由 `yearfix.py` 逐年测出，列在 `YEARFIX` 表里。
2. **1978 年 9 月混入的第二套轨道。** 1978-09-08 至 09-25 约三分之一的点偏离主轨道 1—3.5 万 km。定轨时用上一节点的外推轨道做 400 km 门限，把它们剔除。
3. **GSE 轴的系统偏差。** GSE 的 X 轴相对几何太阳方向约有 +20.5″ 的偏差，数值等于光行差常数。这个值由第 5 次借力确定：只用借力前、或只用借力后的数据分别定轨，要求两段在近月点处衔接（`ls5_check.py`）。
4. **轨道解切换处的跳变。** 原始文件大约每两周换一份轨道解，有 43 处前后两份对不上，相差 0.2—51 千 km，大多在 Z 方向（最大的一处在 1983-02-27）。`build.py` 在这些断点把两侧弹道分开，再把跳变量用平滑过渡分摊到前后最多 ±12 天；离借力或近地点较近时自动收窄，保证这些时刻的几何关系不受影响。`v2/seams.py` 列出断点，`v2/kinkcheck.py` 用“轨迹数值加速度减去引力模型”检查导出轨迹有没有折点。

## 其他脚本

- `v2/analyze.py`、`loo.py`、`nodes_rep.py`：数据覆盖、留一残差、节点残差统计。
- `v2/h_check.py`、`h_back.py`：日心段交叉检验。
- `v2/plotcheck.py`：新旧轨道对比图。
- `v2/seams.py`、`kinkcheck.py`：断点列表与折点检查。
- `v1/`：上一版（锚点加多重打靶）的重建脚本，仅作存档。
