Google 设计系统 · 2014 至今

Material Design

Google 在 2014 年推出的设计系统。它把屏幕想象成一叠有厚度的纸：纸会投下阴影、会滑动和变形，被触碰时泛起墨水般的涟漪。十余年间，它从一套视觉规范长成了覆盖色彩、字体、形状、动效和上百个组件的完整体系。

这一页本身就按 Material 3 的规范搭建。你看到的按钮、卡片和每一种颜色，都是讲解的一部分。

三条最初的原则

layers

材料是隐喻

界面元素像真实的纸：有边缘、有厚度、可以叠放，同时又能自由伸缩变形。光照和阴影告诉你谁在上、谁在下，用户不必学习就能理解层级。

text_fields

鲜明、图形化、有意图

沿用印刷设计的方法：网格、留白、大胆的色彩与字号对比。重要的操作用颜色和位置突出出来，而不是靠装饰。

animation

动效赋予意义

动画不是点缀。元素从哪里来、到哪里去、为什么变化，都由连续的动效交代清楚，让用户始终知道自己身在何处。

十年演进

四个版本，各自回答一个问题

第一版让扁平界面重新有了层次；第二版让各家产品不再长得一模一样；第三版让界面属于用户本人；最新的 Expressive 则想让它更有情绪。下面每张卡片里的按钮，都按那一代的样子绘制。

  1. 2014Material Design

    随 Android 5.0 Lollipop 发布，由 Matías Duarte 领导的团队提出。纸与墨水的隐喻、以 dp 计量的投影、点击涟漪、悬浮操作按钮 FAB，以及饱和度很高的原色调色板。

  2. 2018Material Theming

    回应「所有 App 都像 Google」的批评：颜色、字体、形状都可以按品牌定制，并推出 Material Components 组件库与主题工具。Google 自家产品同时换上更白、更圆润的外观。

  3. 2021Material You · M3

    随 Android 12 发布。系统从壁纸中提取种子色，用 HCT 色彩空间生成整套配色；圆角变大，按钮变成胶囊形，阴影大多让位给表面颜色的深浅。关键词是个人化、自适应。

  4. 2025M3 Expressive

    在 Material 3 之上强化情感表达：基于弹簧物理的动效、一套可以相互变形的抽象形状、更大胆的强调字体，以及按钮组、分体按钮、FAB 菜单等新组件。按住右边的按钮试试。

动态配色

一个种子色，一整套方案

Material 3 不再让设计师一个个挑颜色。系统从壁纸或品牌色里取出一个种子色，生成五组色调板，再按固定的色调编号把颜色分配给几十个「颜色角色」。选一张壁纸，整页都会重新上色。

选择壁纸

HCT：色相、彩度、色调

HCT 是 Google 为 M3 设计的色彩空间。色相和彩度取自 CAM16 色貌模型，色调就是 CIELAB 的明度 L*，0 为纯黑，100 为纯白。

关键在于色调：两种颜色的色调相差 40，对比度大约是 WCAG 的 3 : 1；相差 50，大约是 4.5 : 1。M3 据此规定小元素与背景至少差 50、大元素至少差 40，所以只要按色调编号取色，不管种子色是什么，配色方案基本都能满足无障碍要求。

当前的对比度

本页用 CIELAB LCh 近似 HCT：色调与官方一致，色相和彩度略有出入。官方算法见开源的 material-color-utilities。

五组色调板

每组 13 级色调。主色板保留种子色的彩度，次色板降低彩度，第三色板把色相转动 60°，两组中性色几乎没有彩度，用来铺背景和文字。

颜色角色

组件从不直接引用色值，只引用角色，例如按钮用 primary 填充、文字用 on-primary。切换深色模式时，角色改取另一个色调编号，组件代码一行都不用改。

字体与形状

五种角色，各分大中小

M3 的字体系统一共 15 个样式：Display、Headline、Title、Body、Label 五种角色，各有大、中、小三档。默认字体是 Roboto，中文可以搭配同属 Noto 家族的思源黑体。

形状：从直角到全圆

圆角也被做成了令牌。小元素用小圆角，大容器用大圆角：Chip 是 8dp，卡片 12dp，FAB 16dp，对话框 28dp，按钮则是全圆的胶囊。

M3 Expressive：形状变形

2025 年的更新加入了一套抽象形状，可以作为头像遮罩、图标底板或加载动画，并且能在彼此之间平滑变形。点击右侧的形状切换。

圆形

高度

用阴影和色调表达前后

每个表面都在 z 轴上有一个高度。最初的 Material 用 dp 数值和投影来表达；M3 把高度精简为六级，并且更多地用表面颜色的深浅来区分层级，阴影只留给真正浮起来的元素。

动效

有起点、有终点、有因果

Material 的动画总在解释些什么：卡片展开成详情页，说明详情从哪里来；按下时的涟漪，说明触碰已被接收。缓动曲线和时长同样是令牌。

缓动曲线

「强调」曲线用于大多数界面转场：快速启动、缓慢落定。进入屏幕用减速版，离开屏幕用加速版。

容器变换

点击一张卡片，它会直接长成详情页，而不是凭空切换。这是 Material 最有代表性的转场。

状态层与涟漪

交互状态不换颜色，而是在元素上叠一层半透明的「状态层」，颜色取元素的文字色，透明度固定：

  • 悬停 8%
  • 聚焦 10%
  • 按下 10%，并从触点扩散涟漪
  • 拖动 16%

对话框与提示条

对话框是圆角 28dp 的 Level 3 表面，提示条（Snackbar）从屏幕底部升起，几秒后自动消失。

自适应布局：按窗口宽度换导航

M3 不按「手机、平板」分类，而是按窗口宽度分档，叫作窗口尺寸类别：紧凑（小于 600dp）、中等（600–839dp）、展开（840dp 起），后来又加入了 large 和 extra-large 两档，照顾大平板与外接显示器。每一档换一种导航组件和窗格数量：底部导航栏、导航轨，再到并排的两个窗格。在网页上 1dp 就是 1 个 CSS 像素。

何时使用

好用，但要让它像你自己

Material 是一套为「做产品」而生的系统：规则完整、组件齐全、各平台都有官方实现。它最大的风险也正来自这里：原样套用，你的产品就会长得像 Google。

check适合

  • Android 与跨平台应用：用户已经熟悉这些组件和手势，学习成本最低。
  • 后台、表单密集的工具：输入框、表格、对话框都有成熟的规范和状态定义。
  • 需要快速落地的产品：从原型到上线都有现成的组件库可用。
  • 多人协作的设计系统：令牌化的颜色、字体和形状，天然适合设计与开发对齐。

close慎用

  • 强调品牌个性的营销页：标准组件的辨识度属于 Google，不属于你。
  • 奢侈品、艺术与文化类网站：工程化的秩序感会压过情绪和氛围。
  • iOS 原生应用：与平台习惯冲突，例如返回方式和导航结构。
  • 内容极简的单页：一套完整的系统在这里显得太重。

四个常见错误

每组左边是错误示范，右边是改正后的样子。它们都用本页的令牌画成，会跟着种子色和明暗一起变。

一屏好几个 Filled 按钮

每个按钮都在喊「点我」，用户反而找不到主要操作。一屏只留一个 Filled，其余按重要程度降为 Tonal、Outlined 或 Text。

把色值写死在组件里

左边的卡片写死了 #F3EDF7 和 #1D1B20，右边引用的是 surface-container 与 on-surface。换一张壁纸或切到深色模式，左边就和页面脱节了。

处处都用阴影分层

卡片套卡片、每层都投影，页面又脏又乱。M3 用表面容器的五档色调区分层级，阴影只留给 FAB、菜单、拖动中的元素这些真正浮起来的东西。

只用占位文字当标签

占位文字一输入就消失，用户写到一半就忘了这一栏要填什么，屏幕阅读器也未必读出它。M3 的文本框始终保留标签：聚焦或有值时，它缩小并浮到上方。

让它不像 Google

  1. 把品牌色作为种子色，交给动态配色生成整套方案，而不是只换主按钮的颜色。
  2. 调整形状令牌：全部直角会显得硬朗，全部超大圆角会显得柔软可爱。
  3. 换掉 Roboto。标题用有个性的字体，正文保持易读。
  4. 重画插图和空状态，这是最能体现品牌气质的地方。

实现

把规范落到 CSS 里

Material 的「设计令牌」就是一组有名字的变量。网页上最自然的载体是 CSS 自定义属性：组件只引用名字，主题只改变量的值。下面是本页的核心写法、几个容易踩的坑，以及当前配色的导出与对比度检查。

容易踩的坑

  1. 组件只认角色名。写 var(--md-sys-color-primary)，不写色值。深色模式和换主题只替换变量的值，组件代码一行不改。
  2. 状态层叠在内容下面。用 ::before 铺一层 currentColor，悬停 8%、聚焦和按下 10%。不要去改容器自身的颜色或 opacity，否则文字也会一起变淡。
  3. 触控目标至少 48 × 48dp。图标按钮的图形只有 24dp，点击区域要用内边距补足；相邻目标之间留出间隙。
  4. 图标字体要先占好位置。Material Symbols 是连字字体，加载完成前会把 menu 这样的单词直接显示出来。用 display=block 加固定宽高的容器，再用 icon_names= 只下载用到的图标：本页只加载了 30 个。
  5. 涟漪要尊重「减少动效」。开启后只保留状态层的颜色变化，不画扩散的圆。
  6. 动态配色交给官方工具。正式项目用开源的 material-color-utilities 或 Material Theme Builder 生成令牌；本页用 LCh 近似 HCT，只适合演示和原型。

核心写法

/* 1. 颜色角色：组件只认这些名字 */
:root {
  --md-sys-color-primary: #6750A4;
  --md-sys-color-on-primary: #FFFFFF;
  --md-sys-color-surface: #FEF7FF;
  --md-sys-color-on-surface: #1D1B20;
  --md-shape-full: 9999px;
  --md-ease-emphasized: cubic-bezier(.2, 0, 0, 1);
}
/* 2. 按钮：40dp 高的胶囊 */
.btn-filled {
  height: 40px; padding: 0 24px;
  border: 0; border-radius: var(--md-shape-full);
  background: var(--md-sys-color-primary);
  color: var(--md-sys-color-on-primary);
  font: 500 14px/20px Roboto, sans-serif;
  /* 3. 状态层的容器 */
  position: relative; overflow: hidden; isolation: isolate;
}
.btn-filled::before {
  content: ""; position: absolute; inset: 0; z-index: -1;
  background: currentColor; opacity: 0;
  transition: opacity 150ms linear;
}
.btn-filled:hover::before { opacity: .08; }
.btn-filled:is(:focus-visible, :active)::before { opacity: .10; }
/* 4. 焦点环：3px、secondary 色、外扩 2px */
:focus-visible {
  outline: 3px solid var(--md-sys-color-secondary);
  outline-offset: 2px;
}
