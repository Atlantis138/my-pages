# 轨道数据处理脚本

页面运行时载入的轨道数据 `../data/cassini.json` 由这里的脚本生成（页面本身不需要构建，见 `space-missions/GUIDE.md`）：

```
python3 fetch_all.py       # 从 JPL Horizons 下载巡航段、土星段（10 分钟一点）、九颗卫星、太阳方向、惠更斯号，存入 cache/
python3 fit_moons.py       # 为每颗卫星逐块拟合进动椭圆 → moonfit.json
python3 cands.py           # 用 10 分钟轨迹和卫星模型找出所有可能的近距飞越与近土点 → cache/cands.json、cache/peri10.json
python3 fetch_windows.py   # 在每次飞越、每个低近土点前后下载 1 分钟一点的数据
python3 flybys.py          # 精确的最近点时刻、距离、相对速度，以及卫星模型的改正量 → cache/flybys.json
python3 build.py           # 抽稀轨迹、打包 → ../data/cassini.json
```

脚本都在本目录下运行。需要 `numpy`、`scipy`。Horizons 查询结果缓存在 `cache/`（不入库，首次运行约需 1,000 次查询）。

## 方法

**抽稀。** 逐点贪心地合并线段，要求按时间线性插值的位置与真实轨迹之差不超过“到最近天体（土星或任一卫星）距离的 0.2%”，最小 0.4 km。土星段从约 78.7 万点留下约 2.5 万点，巡航段（误差限 0.08%）留下 731 点。

**卫星。** 每颗卫星按块拟合一条进动椭圆（半长轴、偏心率、倾角，升交点与近点经度线性进动，平经度用三次多项式），块与块之间在交界前后 5% 的时间里平滑过渡。块长：许珀里翁 16 天，菲比 90 天，其余一年。与 Horizons 的最大偏差：

| 恩克拉多斯 | 泰坦 | 特提斯 | 狄俄涅 | 瑞亚 | 弥玛斯 | 伊阿珀托斯 | 许珀里翁 | 菲比 |
|---|---|---|---|---|---|---|---|---|
| 49 km | 82 km | 104 km | 113 km | 157 km | 703 km | 1,156 km | 1,543 km | 2,626 km |

每次近距飞越，再用 1 分钟一点的真实星历求出“真实位置 − 模型位置”及其变化率，在最近点前后 0.3 天内全量叠加、0.6 天处减到零。因此飞越时探测器与卫星的相对位置与 JPL 星历一致（拟合残差小于 4 km）。

**飞越。** 最近点由 1 分钟数据中相对距离最小的样本，按相对速度做直线外推求得。按距离筛选后的次数与 NASA 公布的定向飞越次数一致：泰坦 70,000 km 以内 127 次（下一次已远至 11.8 万 km），恩克拉多斯 5,000 km 以内 23 次。页面按时间顺序给它们命名为 TA、TB、TC、T3—T126 与 E0—E22。

**近土点与圈数。** 取前后 2.5 天内的距离极小值（排除了 3 个由泰坦摄动造成的伪极小值），共 293 个近土点；加上最后坠入土星的一圈，正好 294 圈。
