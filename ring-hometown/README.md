# 环乡

站在一座环世界小镇的中学后山上，看人工昼夜、四季、天气与春照秋照如何改变眼前的河谷，以及头顶那条一直伸进天空的「环」。

在线：<https://atlantis138.github.io/my-pages/ring-hometown/>

## 世界设定（按此计算）

| 项目 | 数值 |
|---|---|
| 环 | 直径 100 000 km，宽 1 000 km，两侧边墙高 50 km；恒星在环外，人住在朝向环心的内表面 |
| 自转 | 每 3 小时 56 分一圈（≈ 1 g） |
| 结构 | 六条辐条连接地面与中央星港；中央镜云在距环轴 3 000–7 000 km、轴向 ±3 750 km 的空间里，依附静止骨架，不随地表自转 |
| 公转 | 半长轴 1 AU，偏心率 0.0475，周期 365.2422 日 |
| 环轴 | 按平均近点角匀速年度转向；真实恒星方向偏离环轴「中心差」，最大约 5.44° |
| 人工昼夜 | 04:30—07:30 渐亮，07:30—16:30 白昼，16:30—19:30 渐暗；对岸与本地差半个昼夜 |
| 气候 | 年均约 15 ℃，夏冬相差约 8 ℃；四季靠人工调节热量形成，冬季白昼照样明亮 |

观察点在环带中线上，眼睛与基准面齐平。按上面的轨道逐圈计算恒星上缘与南墙墙顶的角度（含恒星角半径与 5 万 km 的视差），得到每年两个约 9.7–9.8 日的窗口（春照约在 4 月初，秋照约在 10 月初），每圈至多露出一次，最长约 6.4 分钟。镜云把光从头顶洒下，所以平日影子短而柔和；春照秋照时恒星的光只从南墙顶上掠进来，山顶先亮，光带扫过河谷，高处的空气与云先泛起霞色。

## 画面里的东西

- **近景**：后山、校园（教学楼、跑道、球场）、小镇（沿街民居、公寓、车站、大桥、路灯）、河流、铁路与往来的列车、田野、树林、村落。地形、路网、建筑、树木都是程序生成的，各部分共享同一套河流与铁路距离场，彼此对得上。
- **远景**：一个全屏光线求交着色器。逐像素判断视线落在环面、边墙还是太空；环面上有按经度区分的大陆、海洋、山脉、河流、云带与聚落，每处按自己的本地时被照亮；视线穿过本地大气、真空、再穿过对岸的大气（远端半段按对称性复用积分）。
- **天上**：中央镜云（未分辨的辉光 + 数万个点，按惯性系静止，所以随自转在头顶缓缓漂移，近层与远层方向相反）、静止骨架、星港、辐条、真实方向的恒星（被墙遮住时也在算）、随环体自转的星空与银河。
- **天气**：晴、流云、河谷晨雾、阵雨、阴雨，以及按季节概率的自动天气。云影、雨幕、能见度、湿润的路面与屋顶、水面的风纹和雨点涟漪随之变化。阵雨的雨是否落到观察点，取决于头顶那块云（与着色器同一个云场）。

## 操作

拖动转头、仰望；滚轮或双指缩放；双击回到默认视角。底部可暂停、调速（实时到 ×3600）、拖动「一日」「一年」两条滑杆、一键跳到清晨/白昼/黄昏/夜晚、春照/秋照、四季，并切换天气。右上角可开关标注、说明、全屏与隐藏界面。

快捷键：空格 暂停 · `[` `]` 调速 · `1`–`4` 时刻 · `L` 标注 · `H` 隐藏界面 · `F` 全屏 · 方向键转头 · `+` `-` 缩放。

## 结构

```
ring-hometown/
├── index.html  style.css  app.js（构建产物，可直接打开）
├── build.mjs   esbuild 打包脚本
└── src/
    ├── sim/      时间、历法、轨道与恒星方向、春照秋照搜索、人工昼夜与季节、天气、光照状态
    ├── world/    地理设计、距离场、地形生成、路网与建筑、树木分布
    ├── render/   渲染管线、天空/远景、地形、建筑、树、水、铁路与列车、镜云点层、阴影、雨、后期
    ├── glsl/     着色器
    └── ui/       相机与中文界面
```

## 构建

```
npm install
npm run build      # 生成 app.js
npm run dev        # 本地开发服务器（http://localhost:8123）
npm run typecheck
```

页面只依赖构建出的 `app.js`（已包含 three.js），不需要联网；直接双击 `index.html` 也能运行。
