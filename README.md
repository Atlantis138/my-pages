# my-pages

随手创建的可视化小网页合集。每个作品一个文件夹，入口都是 `index.html`，根目录的 `index.html` 是总目录页。

| 文件夹 | 作品 | 创建日期 |
|---|---|---|
| `sichuan-tibet-railway/` | 川藏铁路三维图志 | 2026-11-04 |
| `everest-terrain/` | 珠峰三维地形图 | 2026-11-03 |
| `quantum-computing/` | 看得见的量子计算 | 2026-11-01 |
| `standard-model/` | 标准模型粒子图谱 | 2026-10-31 |

## 在线浏览

在仓库 Settings → Pages 中，Source 选择 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存后几分钟即可通过
`https://<你的用户名>.github.io/my-pages/` 访问。

## 本地打开

直接双击各文件夹里的 `index.html` 即可（需联网加载字体和 CDN 上的脚本库）。

## 新增作品

1. 新建一个英文短名文件夹，例如 `new-idea/`，放入 `index.html`。
2. 在根目录 `index.html` 的列表里加一张卡片，并更新上面的表格。
