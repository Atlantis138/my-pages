International Typographic Style

二十世纪五十年代，苏黎世和巴塞尔的一批设计师相信：设计应当客观、清晰、可以复用。他们用数学网格组织版面，用无衬线字体排字，左对齐，不加装饰，让信息自己说话。今天大多数「看起来很专业」的网站，骨子里都是这套方法。

这一页也用它写成。按 G 键，或点右上角的「网格」，看看这一页的骨架。

1

原理

Grundsätze

瑞士风格的设计师认为，设计师的任务不是表达自己，而是把信息清楚、客观地组织起来。他们几乎放弃了装饰，只依靠几样工具：网格、无衬线字体、左齐右不齐的排版、悬殊的尺寸对比和留白。

「客观」是这套方法的关键词：用摄影代替插画，用事实代替修辞，用系统代替灵感。右边这张海报是按这些规则排的，把指针移到（或点按）条目上，看每条规则落在哪里。

来历

Geschichte

它的源头是 1920 年代德国的「新文字设计」，在二战后中立的瑞士成熟。苏黎世和巴塞尔的两所工艺美术学校是它的两个中心；1958 年创刊的杂志《新平面设计》把它推向世界，随后进入企业形象、公共导视，最后进入网页。

    柏林的贝特霍尔德铸字厂推出 Akzidenz-Grotesk。半个世纪后，它成了瑞士设计师最常用的无衬线体。

3

网格

Raster

网格把版面划分成等宽的栏和等高的行，栏与行交叉出的格子叫「场」（Feld），也叫模块。所有元素的边都落在网格线上：不同的页面、不同的内容，因此能保持同一种秩序。

1版心 Satzspiegel
页边距以内、放置内容的区域。
2页边距 Rand
版心四周的空白。传统上下边距最大，让版面「站得稳」。
3栏 Spalte
版心被竖向等分出的条带。文字和图片的宽度都是一栏或几栏。
4栏间距 Zwischenraum
栏与栏之间的空隙，防止相邻两栏的文字读串。行与行之间也有同样的间距。
5场 Feld
栏与行交叉出的模块。图片和文字块总是占据整数个场。
6基线网格 Grundlinienraster
按正文行距画出的等距横线，让相邻各栏的文字行横向对齐。

网格是辅助，不是保证。

它允许许多种用法，每位设计师都能找到适合自己的方案。但用网格需要学习，这是一门需要练习的艺术。

约瑟夫·米勒-布罗克曼，《平面设计中的网格系统》，1981（大意）

4

文字

Typografie

瑞士风格几乎只用一类字体：十九世纪末出现的无衬线「怪诞体」（Grotesk），以及它在 1950 年代的改良版。层级不靠换字体，而靠字号、字重和位置。

4.1三款字体

1898

Akzidenz-Grotesk

贝特霍尔德铸字厂 · 柏林

Akzidenz 指广告、表格、票据这类零星的商业印刷。它本是一款平凡的商用字体，五十年后被瑞士设计师重新发现。

1957

Helvetica

米丁格尔与霍夫曼 · 哈斯铸字厂

原名 Neue Haas Grotesk，在 Akzidenz 的基础上改良，1960 年改名。字怀紧凑，笔画末端水平切齐，排出的字块格外整齐。

1957

Univers

阿德里安·弗鲁蒂格 · 巴黎

发布时就有 21 种字重和宽度，用两位数字编号（55 是常规体），开创了把整个字族当作系统来规划的做法。

本页没有嵌入这三款字体：装有 Helvetica Neue 的设备（如 Mac 和 iPhone）会直接显示它，其他设备显示开源的 Inter。中文一律用思源黑体。

4.2层级来自对比

第 4 节 · 文字

层级来自对比

字号、字重和位置，不需要颜色

读者先看到什么、后看到什么，取决于元素之间的差距有多大。瑞士风格把差距拉得很开：标题可以是正文的十几倍，同时只用常规和粗体两种字重。

位置也是层级的一部分。图注和编号退到左边的窄栏，正文从同一条竖线开始，眼睛不用找就知道下一行在哪里。

图注 · 本例只用了一种字体与两种字重

4.3左齐右不齐

西文单词长短不一。两端对齐时只能靠拉大词距来凑齐，窄栏里就会出现一道道白色的「河流」；左齐让词距保持一致，参差的行尾反而成了节奏。打开「自动断词」能缓解，但治不了根。

中文是另一回事：汉字等宽，两端对齐几乎不留痕迹，所以中文正文通常两端对齐。「左齐右不齐」主要是针对西文的规则。

7

用法

Anwendung

瑞士风格最擅长组织大量信息，几乎不会出错，所以成了企业、机构和设计系统的默认选择。它的风险也在这里：做得平庸时，它只剩下冷淡。

适合

  • 企业官网、年报与作品集需要可信、专业、长期不过时的场合。
  • 文档、数据与信息设计表格、图表、时刻表、导视系统。
  • 新闻与长文多栏排版、清晰的标题层级。
  • 设计系统的底层栅格、字阶、间距标尺都直接来自它。

慎用

  • 需要温度和亲和力的品牌做不到位就显得冷淡，像一份模板。
  • 儿童、娱乐和节庆内容克制的语言很难传达热闹与玩心。
  • 内容很少的页面网格的好处来自大量内容的统一；三个元素撑不起一张网格。

7.1四个常见错误

居中对称

所有元素沿中轴排开，每一行的起点都不同，眼睛只能一行一行地找。改成左齐，让文字都挂在同一条栏线上。

字体和字重太多

衬线、斜体、等宽字体一起上，再配三种颜色，层级反而说不清。一种字体、两种字重，差别交给字号和位置。

西文窄栏两端对齐

长单词把行撑得忽紧忽松，中间留下大块空白。窄栏一律左齐；实在要两端对齐，至少打开断词并加宽栏。

大标题用默认字距

字体的默认字距是为正文设计的，放大到几十倍后字母之间会显得很散。大标题收紧到 −0.03 至 −0.05 em，小字反而要略微放开。

它的问题：冷，以及千篇一律

当所有公司都用同一种字体和同一张 12 栏网格，版面就不再传达任何个性。1960 年代末，巴塞尔的魏因加特等人开始有意打破它。今天用瑞士风格，可以这样让它活起来：

  1. 极端的尺度让最大的字大到出格，最小的字小到安静，张力来自两者的差距。
  2. 一种大胆的颜色保留一块纯色作为唯一的情绪出口，其他一律黑白。
  3. 真实的内容真实的照片、数据和文字，比任何装饰都有表情。
  4. 有意打破一次在严格的网格里，让一个元素出血、跨栏或旋转。规则越严，这一下越有力。

8

实现

Technik

CSS Grid 让网格第一次成为浏览器原生的能力，做瑞士风格网页从未这样容易。难的是细节，下面这些都是这一页用到的。

  1. 8.1

    用 minmax(0, 1fr)，不要用 1fr

    1fr 的最小值是内容宽度，一个长单词或一段代码就能把栏撑宽，网格随之歪掉。

  2. 8.2

    用 subgrid 对齐嵌套元素

    本页每一节的正文区都是外层 12 栏的子网格，所以卡片、图表和文字都落在同一组栏线上。

  3. 8.3

    断词需要声明语言

    hyphens: auto 只在元素带有 lang 属性（如 lang="de"）时生效。

  4. 8.4

    让行尾更整齐

    text-wrap: pretty 能避免段末只剩一个词；不支持的浏览器会直接忽略它。

  5. 8.5

    数字要等宽

    年表和表格用 font-variant-numeric: tabular-nums，每一位数字等宽，竖向才能对齐。

  6. 8.6

    网格叠加层与正文共用变量

    按 G 显示的红色栏线是一个固定定位的 12 栏网格，和正文用同一组变量，所以在任何宽度下都严丝合缝。

/* 一组变量，正文和叠加层共用 */
:root {
  --cols: 12;
  --gutter: clamp(12px, 2vw, 24px);
  --margin: clamp(16px, 4vw, 48px);
}
.g {
  display: grid;
  grid-template-columns:
    repeat(var(--cols), minmax(0, 1fr));
  column-gap: var(--gutter);
  padding-inline: var(--margin);
}
.sec-body {
  grid-column: 4 / -1;
  display: grid;
  grid-template-columns: subgrid;
}
h1 {
  font-weight: 700;
  line-height: .9;
  letter-spacing: -0.04em;
}
p { text-align: left; text-wrap: pretty; }
[lang="de"] { hyphens: auto; }
.tl b { font-variant-numeric: tabular-nums; }

/* 按 G 显示：固定定位，套用同一个 .g */
.overlay {
  position: fixed; inset: 0;
  pointer-events: none;
}
