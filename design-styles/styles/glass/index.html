玻璃拟态

Frosted glass for the web

一块半透明的面板，把背后的颜色模糊成一片柔光，再用一道细细的亮边勾出轮廓。它让界面分出前后层次，又不把背景完全挡住。这种质感在 2007 年的 Windows Vista 里就出现过，2020 年随 macOS Big Sur 被叫作「玻璃拟态」，2025 年又借苹果的 Liquid Glass 回到聚光灯下。

这一页的每一块面板都是真正的 CSS 玻璃。拖动背后的光斑，或换一种背景，看玻璃怎样随背景而变。

01 · 原理

一块玻璃，六层效果

CSS 里的玻璃不是一个属性，而是几层效果叠起来的。真正关键的只有第一层 backdrop-filter：它处理的是元素背后已经画好的像素，而不是元素自己。其余几层让玻璃有颜色、有质感、有边界。逐层关掉试试，看每一层少了会怎样。

02 · 来历

从玻璃房子到 Liquid Glass

玻璃进入界面，比「玻璃拟态」这个名字早了十几年。每一代系统都在解决同一个问题：怎样让一层浮在另一层上面，又不让人迷路。每个节点下面都附了一条对网页的启示。

1851 — 1926

先有玻璃房子

1851 年，约瑟夫·帕克斯顿用铁和玻璃为伦敦万国博览会搭起水晶宫。1914 年，布鲁诺·陶特在科隆的德意志制造联盟展上建起玻璃馆，献给写下《玻璃建筑》的诗人保罗·舍尔巴特。1926 年落成的包豪斯德绍校舍，工坊楼整面都是玻璃幕墙。玻璃让人看见另一边，同时又把两边隔开。

网页启示界面里的玻璃也是这样：它告诉用户「后面还有一层」，面板只是暂时浮在上面。

2007

Windows Vista 的 Aero Glass

Vista 给窗口边框加上半透明和模糊，再压上一道光泽高光。这个效果依赖新的桌面窗口管理器和显卡加速，入门的 Home Basic 版本干脆没有它。两年后的 Windows 7 延续了 Aero，到 2012 年的 Windows 8 才被扁平的 Metro 取代。

网页启示玻璃从第一天起就是「有成本」的效果。写玻璃时，先写好它的降级版本。

计算机

2013

iOS 7：去掉纹理，留下半透明

iOS 7 抛弃了拟物化的皮革和木纹，却保留并强化了半透明：控制中心和通知中心是一层模糊的薄片，下面的主屏幕隐约可见。用户从一层滑到另一层时，始终知道自己从哪里来。

网页启示模糊在说「这是临时浮层，底下的内容还在」。抽屉、弹层、工具栏最适合用玻璃。

2017

Fluent Design 的 Acrylic

微软的 Fluent 设计体系推出 Acrylic（亚克力）材质：背景模糊、一层着色，再叠一层细噪点。噪点让大面积的模糊不至于像塑料，也掩盖了渐变色带。

网页启示大面积玻璃加一层很淡的噪点，质感立刻更真实。本页的玻璃都叠了一张 SVG 噪点。

2020

macOS Big Sur，以及一个名字

Big Sur 把半透明铺满了侧栏、菜单栏和通知中心的小组件。同年，设计师 Michał Malewicz 撰文总结这种风格，Glassmorphism 这个名字随之流行。Dribbble 上涌现出大量「彩色光斑 + 玻璃卡片」的作品。

网页启示光斑几乎成了标配，因为没有它们玻璃就看不出来。玻璃本身没有颜色，它的美全部借自背景。

2021

Windows 11 的 Mica

Mica（云母）材质不再实时模糊窗口背后的内容，而是取一次桌面壁纸的颜色，给窗口底色染上淡淡的色调。效果更克制，也更省电。

网页启示大面积背景不必用真正的 backdrop-filter。一张预先模糊好的图，或一层带色调的半透明底色，就能得到相近的气质，代价小得多。

2023

visionOS：悬浮在房间里的玻璃

苹果为 Vision Pro 设计的 visionOS 把玻璃作为窗口的默认材质。窗口悬浮在真实的房间里，玻璃让人既能读内容，又不丢失周围的环境。

网页启示背景是无法控制的真实世界时，玻璃必须在任何背景下都保证可读。网页也一样：用户的壁纸、图片和视频都可能出现在玻璃后面，要按最坏的情况设计。

2025

Liquid Glass：会折射的玻璃

苹果在 2025 年的 WWDC 上发布 Liquid Glass，统一了 iOS 26、macOS Tahoe 26 等系统的界面。它不只是模糊，还像透镜一样折射背后的内容，边缘的高光会随设备移动。发布后它的可读性受到不少批评，iOS 26.1 加入了「着色」选项，让玻璃更不透明。

网页启示右边这块透镜用 SVG 位移滤镜近似边缘折射，可以拖动。这只是近似实现：把 SVG 滤镜用在 backdrop-filter 上目前只有 Chromium 内核支持，其他浏览器会显示为普通模糊。

03 · 视觉规则

四条规则

玻璃拟态的规则不多，几乎都围绕一件事：玻璃本身是透明的，它的样子取决于背后有什么。所以设计玻璃，其实是在设计「玻璃与背景的关系」。

规则 1

文字越多，玻璃越厚

模糊越强、着色越浓，玻璃越「厚」，背景越难干扰文字。只放一个图标的按钮可以很薄，一段正文就需要厚玻璃。下面五档厚度借用了苹果 SwiftUI 的材质命名，数值是本页自定的。每档右下角是按当前配色估算的最差文字对比度。

规则 2

一道光就是边界

玻璃没有颜色，边界全靠一道亮边。比起整圈均匀的 1px 白边，「迎光的一侧亮、背光的一侧暗」的渐变边更像真正的玻璃。在下面的卡片上移动指针，高光会跟着走。

规则 3

背景鲜艳，玻璃中性

颜色来自背后的光斑，玻璃自己只用白或黑着色。模糊会把相邻的颜色混成灰，所以要用 saturate() 把饱和度补回来，这是苹果系统材质的常用手法。

规则 4

越靠近用户，越清楚

层级用三样东西表达：模糊、着色和投影。越上面的层，模糊越强、着色越浓、投影越深。弹窗还要给整个页面再罩一层模糊，把注意力收拢到中间。

字

正文用 400–500 的常规字重，细字体只留给大号数字。模糊背景已经很「软」，文字要稳。

动

背景可以缓慢流动，玻璃自己少动。不要给 blur() 的半径做动画，那是最贵的一种重绘。

形

16–28px 的圆角最常见。嵌套时内圆角 = 外圆角 − 内边距，玻璃的边缘才平行。

04 · 界面

放进网页里

玻璃最适合「浮」起来的东西：导航栏、工具栏、弹层、通知、小组件。主要的行动按钮反而应该用实色，它要从玻璃里跳出来。下面的组件都可以操作。

表单

登录

输入框是一块更「凹」的玻璃：着色更淡、边框更清楚。焦点环用实色，不靠玻璃的明暗。

按钮

层级：实色主按钮 > 玻璃次按钮 > 透明幽灵按钮。禁用状态降低不透明度的同时加上虚线边，不只靠颜色。

筛选标签可以多选，选中后变成实色；搜索框是一条胶囊形的薄玻璃，放在图片上也读得清。

控制中心

开启的磁贴换成不透明的强调色，状态不靠透明度的细微差别来表达。

通知

通知层叠时，越早的那条越往后退：缩小、变淡。最多同时显示三条。

06 · 好与坏

什么时候用，容易错在哪

玻璃拟态最大的风险是：它的样子不由你决定，而由玻璃背后的内容决定。设计时看着很美的卡片，换一张背景图就可能读不清。

适合

  • 浮在内容上的东西：导航栏、工具栏、底部标签栏、抽屉。
  • 叠在图片和视频上的信息：播放器控件、地图上的卡片、相册说明。
  • 小而独立的组件：天气、音乐、日程小组件。
  • 科技与产品发布页的首屏：背景可控、文字少、氛围优先。

慎用

  • 长篇正文和数据表格：背景的明暗起伏会一直干扰阅读。
  • 背景不受控的地方：用户上传的图片、可换的主题、视频流。
  • 低端设备为主的产品：大面积模糊会掉帧、发热、耗电。
  • 整页铺满玻璃：所有东西都半透明，就没有哪一层是「浮起来」的了。

四个常见错误

背后什么都没有

纯色背景上的玻璃只是一块浅色方块，模糊没有东西可模糊。要么给它一个有内容的背景，要么干脆用实色卡片。

白字压在亮斑上

光斑漂到文字背后，白字就看不清了。加厚着色（换成深色玻璃），或在文字下面单独垫一层更不透明的底。对比度要按背景最亮的地方算。

玻璃套玻璃

外层带 backdrop-filter 时会成为内层的「背景根」：内层只能把外层已经画好的东西再模糊一遍，多算一次，几乎看不出差别，层级反而更含糊。内层改用半透明的实色，省掉一次模糊，边界也更清楚。

主按钮也做成玻璃

玻璃按钮会和背景融在一起，用户找不到最重要的那个行动。主按钮用不透明的实色，玻璃留给次要操作。

07 · 实现

写好它的几个要点

backdrop-filter 在 2019 年的 Chrome 76、2022 年的 Firefox 103 默认开启，2024 年才成为各主流浏览器都不需要前缀的 Baseline 特性。旧版 Safari 只认 -webkit- 前缀，所以两行都要写。

先写降级

用 @supports 判断，不支持时换成更不透明的实色底。注意要同时检测带前缀和不带前缀的写法，否则旧版 Safari 会被误判为不支持。

尊重「降低透明度」

系统设置里的「降低透明度」可以通过 prefers-reduced-transparency 读到（目前只有部分浏览器支持），同时也照顾 prefers-contrast: more。点右上角的方块按钮看本页的实色版本。

小心「背景根」

按规范，祖先元素带有 filter、opacity < 1、mask、clip-path、mix-blend-mode 或 backdrop-filter 时，会成为里面玻璃的「背景根」，玻璃只能模糊这个祖先之内的内容。最常见的坑：给玻璃的父元素做淡入动画，模糊在动画期间失效。各浏览器在这一点上的实现还有差异，要实测。

控制面积与层数

模糊的开销大致和面积、半径成正比，背后的内容一动，玻璃就要逐帧重新计算。本页的整页背景是静止的，只有首屏的光斑在流动。整屏大背景可以学 Mica，用预先模糊的图片代替实时模糊。

渐变边框用遮罩

border-image 不支持圆角。渐变高光边要用一个伪元素：背景铺渐变，再用 mask-composite: exclude 挖掉中间，只留 1px 的边。

:root {
  --glass-tint: rgb(255 255 255 / .2);
  --glass-solid: rgb(240 240 250 / .94);
  --glass-blur: 20px;
}
.glass {
  position: relative;
  background: var(--glass-tint);
  -webkit-backdrop-filter: blur(var(--glass-blur)) saturate(180%);
          backdrop-filter: blur(var(--glass-blur)) saturate(180%);
  border-radius: 24px;
  box-shadow: 0 20px 50px rgb(20 10 60 / .2);
}
/* 渐变高光边：伪元素 + 遮罩挖空 */
.glass::before {
  content: ""; position: absolute; inset: 0;
  border-radius: inherit; padding: 1px;
  background: linear-gradient(135deg,
    rgb(255 255 255 / .8), rgb(255 255 255 / .1) 40%,
    rgb(255 255 255 / .05) 60%, rgb(255 255 255 / .4));
  -webkit-mask: linear-gradient(#000 0 0) content-box,
                linear-gradient(#000 0 0);
  -webkit-mask-composite: xor;
          mask-composite: exclude;
  pointer-events: none;
}
/* 不支持模糊：换成实色 */
@supports not ((backdrop-filter: blur(1px))
           or (-webkit-backdrop-filter: blur(1px))) {
  .glass { background: var(--glass-solid); }
}
/* 用户要求降低透明度或提高对比度 */
@media (prefers-reduced-transparency: reduce),
       (prefers-contrast: more) {
  .glass {
    background: var(--glass-solid);
    -webkit-backdrop-filter: none; backdrop-filter: none;
  }
}
