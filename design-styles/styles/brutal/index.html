野兽派网页（Web Brutalism）不给页面化妆：浏览器默认的字体、蓝色带下划线的链接、生硬的边框、原生的按钮，统统原样留着。

它的名字借自 1950 年代的粗野主义建筑：混凝土拆模后不抹灰、不贴面，木模板的纹理直接留在墙上。网页的「混凝土」是 HTML。这一页就按这个思路写成：没有网页字体，没有图片，没有圆角，没有阴影，没有渐变，没有缓动。颜色全部交给浏览器的系统颜色。

右边的控制台可以把这一页的样式表整个拆掉，或者把每个 HTML 元素的「模板印痕」标出来。拆掉之后它依然能读、能点、能填表。

§1

材料诚实

粗野主义建筑最核心的主张是：材料以本来的面目示人，结构一眼看得出来。翻译到网页上，就是让 HTML 做 HTML 该做的事，不用 CSS 和 JavaScript 去假扮别的东西。

建筑与网页的对照
粗野主义建筑野兽派网页
裸露的混凝土，不抹灰、不贴面浏览器默认样式与系统字体，不加装饰层
木模板的纹理留在墙上结构直接可见：边框、表格线、<hr>、标签名
管道和设备不藏进吊顶链接就是带下划线的链接，按钮就是按钮
功能决定体量内容决定版式，不为「好看」加无关内容
大体量、重复的单元超大号字、重复的网格单元、粗重的分隔线

§2

从混凝土到超链接

一张表就够了。左边是建筑，右边是网页，最后一栏是它留给今天的前端的东西。

年表
年份事件对网页的启示
1950据说瑞典建筑师汉斯·阿斯普伦德用「新粗野主义」(nybrutalism) 戏称同行设计的一座砖砌住宅，这个词后来经英国同行传开。名字起初带着玩笑。「野兽派网页」这个称呼也一样，不必把它看得太严肃。
1952勒·柯布西耶设计的马赛公寓落成。béton brut（原始混凝土）成了这类建筑的标志，「粗野」一词也与它相关。材料就是表面。网页的「材料」是 HTML 元素和浏览器默认样式。
1955英国评论家雷纳·班纳姆发表《新粗野主义》，把「结构清楚可读」「材料按本来面目呈现」列为要点。对应到网页：语义化的 HTML，以及看得出结构的版式。
1966班纳姆出版《新粗野主义：伦理还是美学？》。网页上同样有两派：追求坦率、快速、好用的「伦理派」，和只追求「看起来粗糙」的「美学派」。
1982伦敦巴比肯艺术中心开幕，所在的巴比肯屋村是粗野主义最大的建筑群之一。大体量 + 重复单元。网页里对应的是巨型字和一格一格的重复网格。
1991蒂姆·伯纳斯-李上线第一个网站：纯文本、标题和超链接。网页一出生就是「野兽派」的：那时还没有 CSS。
1996CSS 1 成为 W3C 推荐标准。同一时期，Craigslist 从一个邮件列表起步，网站的样子多年几乎没变。「丑」的网站可以很成功：用户要的是信息和速度。
2014设计师 Pascal Deville 创建 brutalistwebsites.com，收集刻意「不设计」的网站，「网页野兽派」由此得名。它是对千篇一律的模板网站的反叛：同样的大图、同样的三栏卡片。
2017史密森夫妇设计的伦敦罗宾汉花园开始拆除，维多利亚与阿尔伯特博物馆保存了其中一段立面。粗野建筑常被嫌弃、被拆除；网页倒是反过来，那些「丑」网站往往活得最久。
2018开发者 David Bryant Copeland 发布《野兽派网页设计指南》，把这种风格落到可用性上，提出七条规矩。本页 §4 就按这七条来组织组件。

§3

规格书

野兽派没有调色板，也没有字体授权。它的「规范」是一组克制：用什么、不用什么。

3.1 字体：系统自带

衬线 Times New Roman / 宋体

等宽 Courier New / 等宽字

无衬线 Arial / 黑体

不下载任何网页字体。你看到的具体字形取决于你的系统：Windows、macOS、安卓上各不相同。这不是缺陷，而是这种风格的一部分。

3.2 颜色：交给浏览器

  • Canvas底色
  • CanvasText文字
  • LinkText链接
  • VisitedText访问过
  • Mark高亮
  • ALERT错误（唯一自定义色）

这些是 CSS 的系统颜色关键字，由浏览器按明暗模式解析。切到暗色看看，链接蓝会自动变浅。

3.3 线：结构，不是装饰

1px · 表格与细分隔

3px · 区块边界、按钮、输入框

8px · 章节之间

只有三种粗细。线条用来标出结构，所以从不做成虚线、渐变或圆头。

3.4 尺寸：反差要大

10: 1 · 最大的字和正文之比

页面上只有两种字号最显眼：巨大的标题，和正常大小的正文。中间档位越少，越有野兽派的味道。

3.5 交互：瞬间反色

悬停这个链接

悬停时前景色和背景色直接对调，没有过渡。焦点是 4px 的实线加高亮底色，比任何精致的焦点环都清楚。

3.6 装饰：只在需要时

+------------------------+
|  DECORATION BUDGET: 1  |
+------------------------+

允许的装饰本身也是「原材料」：ASCII 字符画、<hr>、一条跑马灯。它们不需要图片，也不需要额外的请求。

§4

七条规矩，一套组件

Copeland 的《野兽派网页设计指南》把这种风格落到了可用性上。下面按他的七条规矩（意译）逐条给出网页组件。所有组件都是原生 HTML 元素，样式只有边框、字体和反色。

  1. 1内容在任何合理的屏幕上都可读

    野兽派的响应式几乎不用写：正文用 max-width: 70ch 限宽，卡片网格用 auto-fit 自动换行，标题用 clamp() 缩放。下面这个示例页一条媒体查询都没有。

    粗糙的网页，结实的内容。

  2. 2只有链接和按钮会响应点击

    用 <div onclick> 假装的按钮，鼠标能点，键盘却摸不到，屏幕阅读器也不知道它是按钮。先用鼠标点两个都试试，再按 Tab 键走一遍。

    div 被点了 0 次 · button 被按了 0 次（其中 0 次来自键盘）

  3. 3链接有下划线，按钮看起来像按钮

    普通链接 · 访问过的链接（示意） · 有焦点的链接

    [首页] [文章] [关于] [RSS]

    主按钮用反色实底，次按钮只有 3px 边框，禁用的按钮用虚线边加删除线，不只靠变淡。当前导航项用高亮底色，还带 aria-current。

  4. 4后退键照常工作

    下面的标签页没有用一行 JavaScript：每个标签就是一个指向 #id 的链接，CSS 的 :target 决定显示哪一块。点几个标签，再按浏览器的后退键，标签会一个个退回去。

    HTMLCSSJavaScript

    HTML 是混凝土。结构、语义、链接、表单都在这一层。它必须独立成立：拆掉另外两层，页面依然完整。

    CSS 是模板的纹理。野兽派只用它做三件事：定字体、画线、处理反色和焦点。装饰性的属性一律不用。

    JavaScript 是可选的设备。它只增强，不承重。本页关掉 JS 后，除了统计数字和几个演示，所有内容都还在。

  5. 5内容靠滚动浏览

    不做轮播，不劫持滚动，不做横向翻页。信息多的时候用表格和折叠，让用户一眼看完、自己决定看哪里。点表头可以排序。

    FAQ：野兽派网页就是「没做完的网页」吗？

    不是。没做完的网页是缺东西；野兽派网页是把不需要的东西拿掉。它的每一条边框、每一个下划线都是刻意保留的。

    FAQ：为什么用原生的 <details> 做折叠？

    它自带键盘操作、展开状态和无障碍语义，浏览器的页内搜索也能搜到折叠里的文字。自己用 div 拼一个，很难做得这么全。

  6. 6装饰只在需要时出现，不放无关内容

    提示、表单和进度条都用原生元素，状态写成文字前缀，而不是只靠颜色或图标。

    ERROR: 付款没有完成。你的卡没有被扣款，请重试。

    NOTE: 周日 14:00 起维护一小时。

    表单用浏览器自带的校验；用户填错离开输入框后（:user-invalid），边框变成错误色并加粗。对话框是原生 <dialog>，Esc 可以关闭，焦点会自动回到按钮上。

  7. 7性能就是功能

    不加载用不到的东西，页面自然就快。这一页的全部重量就在首屏的控制台里：正在统计…… 没有网页字体、没有图片、没有框架，也没有第三方脚本。

§6

粗糙 ≠ 难用

野兽派最常见的失败，是把「不修饰」误解成「不考虑用户」。外表可以粗，可用性不能打折。

适合

  • 艺术家、设计师、独立创作者的个人站
  • 宣言、活动、实验项目这类「有态度」的页面
  • 开发者主页、文档、更新日志
  • 独立出版、小众媒体、需要极快加载的信息站

慎用

  • 电商、金融、医疗：用户可能以为网站坏了或不可信
  • 面向不熟悉网页的人群：他们更依赖熟悉的界面惯例
  • 品牌需要「精致、高级」的场合
  • 复杂的应用界面：原生控件不够用时，硬撑会更难用

四个常见错误

为了「好看」去掉焦点框

outline: none 让键盘用户不知道自己在哪。野兽派的焦点可以很粗野：4px 实线加高亮底色，比默认的还显眼。

用低对比的颜色表达态度

纯黄字放在白底上，对比度只有 1.1 : 1 左右。要用黄色就把它当底色，上面放黑字。

巨型字在手机上撑破版面

固定的超大字号在窄屏上会溢出，导致横向滚动。用 clamp() 跟随宽度缩放，再加上 overflow-wrap: anywhere 兜底。

谜一样的导航

只用符号当导航很「酷」，但没人知道该点哪个。野兽派的导航就是写清楚的文字链接。

§7

整站样式表

一个野兽派网站的基础样式，二十来行就够了。下面这段可以直接用在任何只有 HTML 的页面上。

/* 野兽派基础样式：只有这些 */
:root { color-scheme: light dark; }   /* 深色模式交给浏览器 */
body {
  max-width: 70ch; margin: 0 auto; padding: 1rem;
  font: 1.125rem/1.5 "Times New Roman", Times,
        "Songti SC", SimSun, serif;
  background: Canvas; color: CanvasText;   /* 系统颜色 */
}
h1 { font-size: clamp(2.5rem, 12vw, 8rem); line-height: .9;
     overflow-wrap: anywhere; }
a { color: LinkText; text-decoration-thickness: 2px;
    text-underline-offset: 3px; }
a:visited { color: VisitedText; }
a:hover, button:hover { background: CanvasText; color: Canvas; }
:focus-visible { outline: 4px solid CanvasText; outline-offset: 2px;
                 background: Mark; color: MarkText; }
button, input, select, textarea {
  font: inherit; color: CanvasText; background: Canvas;
  border: 3px solid CanvasText; border-radius: 0; padding: .3em .6em;
}
hr { border: 0; border-top: 3px solid; }
table { border-collapse: collapse; }
th, td { border: 1px solid; padding: .25em .5em; text-align: left; }
pre, code { font-family: "Courier New", Courier, monospace; }
img { max-width: 100%; height: auto; }
@media print { a[href^="http"]::after { content: " (" attr(href) ")"; } }
  1. 系统颜色 + color-scheme = 免费的深色模式。Canvas、CanvasText、LinkText 由浏览器按明暗解析，在 Windows 的高对比度（强制颜色）模式下也天然正确。本页的 [暗色] 按钮只改了一个属性：color-scheme。
  2. 字体栈写全，以通用族结尾。英文字体后面跟上中文字体，最后写 serif 或 monospace。安卓上没有 Times New Roman，会落到系统衬线体。
  3. 下划线可以更粗野，但别压字。text-decoration-thickness 和 text-underline-offset 让下划线更粗、离字更远，中文也不会被划到。
  4. 没有过渡。反色是瞬间的。唯一的动画是跑马灯，开启「减少动效」时它会停下（老旧的 <marquee> 元素已被废弃，用 CSS 动画代替）。
  5. 先拆再装。写样式之前，先确认页面在没有 CSS 时完整可用：标题层级对、表单有 label、链接文字说得清去哪。首屏的 [拆掉全部 CSS] 就是这项检查。
  6. 打印也是一种屏幕。打印时把外链地址印在链接后面，纸上也能「点」。
