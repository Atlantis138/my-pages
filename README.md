# my-pages

随手创建的可视化小网页合集，在线浏览：https://atlantis138.github.io/my-pages/

| 作品 | 文件夹 |
|---|---|
| 设计风格图鉴 | `design-styles/` |
| 微观之旅 | `microcosm/` |
| 卡西尼–惠更斯号 | `cassini-mission/` |
| ISEE-3 航迹 | `isee3-trajectory/` |
| 川藏铁路三维图志 | `sichuan-tibet-railway/` |
| 珠峰三维地形图 | `everest-terrain/` |
| 看得见的量子计算 | `quantum-computing/` |
| 标准模型粒子图谱 | `standard-model/` |

本地查看请在仓库根目录运行 `python -m http.server`，再打开 http://localhost:8000 （直接双击打开时，珠峰页的数据文件会载入失败）。
