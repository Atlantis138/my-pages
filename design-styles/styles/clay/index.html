1

原理

三道阴影，一块黏土

黏土感全部来自 box-shadow：一道外投影把元素托起来，一道浅色内阴影在迎光的左上方鼓出高光，一道深色内阴影在背光的右下方压出暗部。再配上一个大圆角和一种自己的颜色。逐项关掉看看。

2

来历

从橡皮泥到界面

黏土拟态这个名字只有几年历史，但「捏出来的、软软的、会弹的」这种趣味，在黏土、定格动画和民间泥塑里已经很久了。每一段都附了一条落到网页上的启示。

1897 年前后 · 英国巴斯

一块不会干的黏土

美术教师威廉·哈巴特想给学生找一种练雕塑用、放多久都不会变干的材料，调出了油性的造型黏土 Plasticine，后来成了全世界孩子手里的橡皮泥。它柔软、鲜艳、捏坏了可以重来。

网页启示黏土给人的第一感觉是「可以放心地按」。这种风格天生适合鼓励尝试的界面：新手引导、练习题、游戏化的任务。

明清至今 · 无锡与天津

圆滚滚的民间泥塑

无锡惠山泥人里最有名的「大阿福」，胖脸圆身、色彩明快，是招福的吉祥物；天津的「泥人张」则以写实的彩塑人物闻名。泥塑的造型往往饱满圆润，没有尖角。

网页启示饱满的圆形自带亲切感。界面里的吉祥物、空状态插画和头像，用圆润的大块面最容易讨人喜欢。

1950 年代 — 1990 年代

一帧一帧捏出来的动画

美国动画师阿特·克洛基在 1950 年代用黏土做出了绿色小人 Gumby；威尔·文顿的工作室把这种动画叫作 Claymation，并凭《Closed Mondays》获得奥斯卡最佳动画短片；英国的阿德曼工作室后来做出了《超级无敌掌门狗》。黏土角色每一帧都被手捏过，形状总在微微「呼吸」。

网页启示黏土风格的动效可以「有点不完美」：待机时轻轻起伏的吉祥物、加载时被捏扁又弹起的圆点，比机械的匀速旋转更有生命感。

1981

动画的第一条原则：挤压与拉伸

迪士尼动画师弗兰克·托马斯和奥利·约翰斯顿在《生命的幻象》中总结了十二条动画原则，排在第一的就是「挤压与拉伸」：物体落地时被压扁，弹起时被拉长，但体积保持不变。

网页启示按钮按下时横向变宽、纵向变扁，松手后带一点过冲地弹回，就是在借用这条原则。首屏的团子会实时算出拉伸与压缩的乘积，它始终是 1。

2020 年前后

柔软的 3D 插画

随着 Blender 等 3D 工具普及，Dribbble 上流行起圆润、哑光、像充气玩具一样的 3D 图标和角色。设计师开始想：界面本身能不能也有这种手感？

网页启示黏土拟态常和 3D 插画一起出现。界面组件用 CSS 做出体积，插画用 3D 渲染，两者的光源方向要一致：本页统一是左上方。

Clay

2021

有了名字：Claymorphism

设计师 Michał Malewicz 把这种风格命名为 Claymorphism，并总结出它的 CSS 配方：一道外投影加两道内阴影。和之前流行的几种「拟态」不同，它的元素有自己的颜色，对比度也好得多，因此能真正用进产品里。

网页启示它的全部视觉只靠 border-radius 和 box-shadow，没有图片、没有滤镜，任何浏览器都能画，降级成本几乎为零。

color-mix()linear()

2023

CSS 补齐了最后两块

color-mix() 让高光和暗部可以直接从一个底色推导出来，不必再手算三个色值；linear() 缓动函数则能用一串采样点描出真正的弹簧曲线。两者都在 2023 年进入了各主流浏览器。

网页启示现在一整套黏土组件只需要一个变量 --c：换一个颜色，阴影自动跟着变；按下和松开的回弹用纯 CSS 就能写出来。本页的「工坊」可以生成这两段代码。

3

视觉规则

形、色、光、字、动

黏土拟态的规则都很「具体」：圆角给多大，阴影用什么颜色，按下时压扁多少。把这几条定成设计令牌，整套界面就能保持同一种手感。

形 · Shape

圆角要大，而且要同心

小元素的圆角接近短边的一半，卡片 28–40px。卡片里再套一块时，内圆角 = 外圆角 − 内边距，两条边才平行，否则内块的四角会显得「鼓包」。

色 · Color

阴影是彩色的

高光和暗部都从元素自己的颜色推导：高光往白色混，暗部往深葡萄紫混，而不是往黑色混。外投影也带一点紫，整页才干净。切到「灰黑阴影」看看区别。

光 · Light

整页只有一盏灯

光从左上方来：高光永远在左上，暗部和投影永远在右下。把三道阴影的偏移写成同一组变量，任何组件都不会「光源打架」。

字 · Type

圆头字体，字重要足

英文用 Fredoka、Nunito 这类圆头字体，标题 600 以上才撑得住鼓鼓的形状；中文标题用粗一档的黑体。糖果色上的文字一律用深葡萄紫，白字在浅色黏土上读不清。

Squishy 黏糊糊

深字 ✓白字 ✗深字 ✓白字 ✗

动 · Motion

会弹的才是黏土

同样从左滚到右，三种缓动的手感完全不同。ease 平稳但「硬」；cubic-bezier 只能过冲一次；linear() 可以描出真正的弹簧：冲过头、晃两下、停稳。黏土的按压、开关、弹窗都适合最后一种。

界面

一套可以按扁的组件

黏土组件的关键是「按下有反馈」：按钮被压扁、开关的圆钮像果冻一样滑过去、提示从下面弹出来。下面是一个儿童学单词应用的零件，都可以操作。

按钮

按下时 scale(1.06, .88)：横向变宽、纵向变扁，体积大致不变；内阴影同时变浅，像被压实了。禁用的按钮直接「瘪掉」：没有体积、虚线边。

6

好与坏

什么时候用，容易错在哪

黏土拟态的可读性比大多数「拟态」都好，它真正的风险在气质：可爱、轻松、孩子气。用对了地方让人想一直按；用错了地方显得不够专业。

适合

  • 儿童与教育产品：学单词、练口算、阅读打卡。
  • 游戏化的任务与奖励：连续打卡、徽章、排行榜。
  • 品牌吉祥物与营销页：角色、插画和组件共用一种手感。
  • 引导页与空状态：让第一步和「什么都没有」显得友好。

慎用

  • 金融、医疗、法律等严肃场景：圆鼓鼓的按钮会削弱信任感。
  • 信息密集的后台和长表格：每一行都鼓起来，层级就没了。
  • 几百个元素的长列表：三层大模糊阴影会拖慢滚动。
  • 需要极简、克制的品牌：糖果色和弹跳动效很难「收」。

四个常见错误

阴影用灰黑色

半透明黑做暗部，橙色会发脏、发棕。暗部往同色系的深色混，外投影带一点背景的色相。

白字放在糖果色上

薄荷绿上的白字对比度只有 1.5 : 1 左右。糖果色本身很浅，文字要用足够深的颜色，本页统一用葡萄紫。

圆角不同心

内外用同一个圆角，内块的四角会顶出去，看起来像鼓包。内圆角取「外圆角 − 内边距」。

每一样东西都鼓起来

所有元素都是彩色黏土，眼睛就不知道该看哪里。只给可交互和最重要的元素体积，其余内容平铺在底色上。

7

实现

写好它的几个要点

黏土拟态只用到很老的 CSS：border-radius 和多重 box-shadow。新特性只是让它更好维护。

一个变量管一块黏土

把底色写成 --c，高光和暗部用 color-mix() 从它推导。换颜色只改一个值，三道阴影一起变。

按压动画只动 transform

给 box-shadow 做过渡，每一帧都要重新计算大面积的模糊。按下时主要靠 transform: scale()，阴影的变化尽量小、尽量快。

别让 overflow 吃掉投影

外投影画在元素外面。父元素一旦 overflow: hidden，右下角的投影会被整齐地切掉。给容器留出内边距，或者只在需要裁剪的那一层设置。

焦点环要和圆角一起圆

现代浏览器的 outline 会跟随 border-radius。用 3px 深色实线加 4px 的间距，在任何糖果色上都看得清。

尊重「减少动效」

在 prefers-reduced-motion: reduce 下去掉弹跳与过冲，只保留颜色和阴影的变化。导航栏的波浪按钮可以在本页手动切换这个效果。

深色版要单独调

深色底上，暗部要往黑色混得更多、高光要收得更弱，外投影用更深的黑。黏土块本身保持明亮，像夜里的糖果。

:root {
  --ink: #3D2C5C;              /* 葡萄紫：文字与暗部的方向 */
  --drop: rgb(61 44 92 / .2);
  --depth: 10px;                 /* 体积：内阴影的大小 */
  --lift: 14px;                  /* 浮起：外投影的偏移 */
  --spring: linear(0, .27, .73, 1.03, 1.12, 1.06, .99, .98, 1);
}
.clay {
  --c: #B79CFF;
  background: var(--c);
  color: var(--ink);
  border-radius: 32px;
  box-shadow:
    var(--lift) calc(var(--lift) * 1.25) calc(var(--lift) * 2.5) var(--drop),
    inset var(--depth) var(--depth) calc(var(--depth) * 2)
      color-mix(in oklab, var(--c), white 65%),
    inset calc(var(--depth) * -1) calc(var(--depth) * -1) calc(var(--depth) * 2)
      color-mix(in oklab, var(--c), var(--ink) 28%);
  transition: transform .5s var(--spring);
}
.clay:active {
  --depth: 6px; --lift: 6px;
  transform: scale(1.06, .88);      /* 被按扁 */
  transition-duration: .12s;
}
.clay-in {                      /* 凹槽：输入框、轨道 */
  box-shadow:
    inset var(--depth) var(--depth) calc(var(--depth) * 2)
      color-mix(in oklab, var(--c), var(--ink) 18%),
    inset calc(var(--depth) * -1) calc(var(--depth) * -1) calc(var(--depth) * 2)
      color-mix(in oklab, var(--c), white 70%);
}
@media (prefers-reduced-motion: reduce) {
  .clay { transition: none; }
  .clay:active { transform: none; }
}
