设计风格图鉴

25 种可以直接用在网页前端的视觉风格。每张卡片左侧是用该风格真实绘制的活体标本，可以悬停、可以点击；右侧记录它的来历、特征、适用场景、字体建议和关键 CSS。风格按源流归入四个谱系，便于对照和挑选。

装饰强度 视觉存在感有多强实现难度 用 CSS 做好需要的功夫可读性 长时间阅读与操作是否舒适色块可点击复制色值

按目标挑选

先想清楚页面要传达的感觉，再从对应的风格里选一个做主调。

一主一辅

选一种风格做主调，最多再从另一种里借一两个元素，例如瑞士网格配新野兽派按钮。同时混三种以上，页面就失去了辨识度。

装饰放在首屏

装饰强度高的风格适合首屏、活动页和空状态。正文、表单和数据区域退回中性排版，读起来才不累。

检查对比度

可读性评分在 3 以下的风格，正文与背景对比度要单独核对。WCAG AA 要求正文至少 4.5 : 1，大标题至少 3 : 1。

25 份标本全部用 HTML 与 CSS 绘制，没有使用任何图片。
